# AI Landing Page Master

Got it — you don’t just want a prompt… you want a MASTER PROMPT that can drive any AI builder to produce a production-level landing page.

Here’s a high-leverage, plug-and-play master prompt (this is what senior product designers actually use internally 👇)

🔥 MASTER AI BUILDER PROMPT (CODEMANTIX LANDING PAGE)

Copy everything below and paste into your AI builder:

Design a high-converting, modern, single-page landing website for a tech education brand called:

Codemantix Collectives Bootcamp

🎯 PRIMARY GOAL

Maximize user conversion into bootcamp applications.

This is NOT just a marketing page — it should feel like a product experience that builds trust, reduces anxiety, and drives action.

🧱 CORE STRUCTURE

Create a single-page landing site with smooth scrolling navigation.

⚠️ CRITICAL RULE:
ALL buttons, links, and CTAs MUST:

Scroll to sections within the same page

Use anchor links (no external navigation)

Example: #curriculum, #application, #pricing

📌 REQUIRED SECTIONS (WITH IDS)

1. HERO (#hero)

Strong, outcome-driven headline

Subheadline that communicates transformation

Show credibility (mentorship, real-world projects)

CTAs:

Primary: Apply Now → #application

Secondary: See What You’ll Learn → #curriculum

2. TRUST / SOCIAL PROOF (#proof)

Testimonials (students or outcomes)

Stats (job placements, projects built)

Logos or affiliations (if available)

CTA:

“Join the Next Cohort” → #application

3. ABOUT THE BOOTCAMP (#about)

Who it’s for (beginners, career switchers, students)

What makes Codemantix different

Key benefits:

Hands-on learning

Mentorship

Real-world projects

CTA:

“Explore Curriculum” → #curriculum

4. CURRICULUM (#curriculum)

Structured breakdown (weeks/modules)

Each module shows:

Skills learned

Tools used

Outcome/project

Make it:

Scannable

Card-based or accordion layout

CTA:

“Start Your Learning Journey” → #application

5. HOW IT WORKS (#how-it-works)

Step-by-step onboarding:

Apply

Get accepted

Start learning

Build projects

Graduate

CTA:

“Apply in Minutes” → #application

6. TRACKS / COURSES (#tracks)

Display available programs like:

UI/UX Design

Web Development

Data / Product (if applicable)

Each card:

Short description

Outcome

CTA:

“Choose Your Track” → #application

7. VALUE / PRICING (#pricing)

Show pricing or “Request pricing”

Emphasize value:

Mentorship

Projects

Career support

CTA:

“Secure Your Spot” → #application

8. FAQ (#faq)

Answer objections:

Do I need experience?

Is it beginner-friendly?

Is it remote?

Duration?

CTA:

“Still have questions?” → #application

9. FINAL CTA / APPLICATION (#application)

Strong emotional close

Reinforce transformation

Include:

Application form OR

Button (Apply Now)

🧭 NAVIGATION

Sticky navbar

Links scroll to:

#about

#curriculum

#tracks

#pricing

#faq

#application

🎨 DESIGN DIRECTION

Style:

Modern, clean, tech-focused

Inspired by top bootcamps (but unique)

UI:

Large bold typography

Strong contrast

Card-based layout

Generous whitespace

Interactions:

Smooth scroll

Subtle animations (fade, slide)

Hover states on buttons

🧠 UX PRINCIPLES

One primary goal: Apply

Keep CTAs consistent across sections

Reduce cognitive load

Make curriculum easy to skim

Build trust BEFORE asking for commitment

🔥 CTA SYSTEM (VERY IMPORTANT)

Use these CTA variations across the page:

Apply Now

Start Your Journey

Join the Bootcamp

Secure Your Spot

Explore Curriculum

ALL must scroll to relevant sections (mostly #application or #curriculum)

📱 RESPONSIVENESS

Fully mobile-first design

Optimize spacing, stacking, and tap targets

Sticky CTA on mobile (Apply Now)

⚙️ FINAL OUTPUT REQUIREMENTS

The result should:

Feel like a real SaaS/product landing page

Be conversion-optimized

Have no dead links

Keep users flowing downward toward application

🚫 DO NOT

Do NOT create multiple pages

Do NOT link outside the page

Do NOT overcomplicate navigation

Do NOT bury the CTA

✅ SUCCESS =

A user lands → scrolls → understands value → trusts brand → clicks Apply Now.. USE THE COLOR PALETTE AND LOGO  AS REFERENCE IN THE ATTACHED FILE
